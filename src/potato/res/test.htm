About Potato

Potato is a lightweight web browser written in C++ for Windows. It does not embed a third-party web view: every part of the rendering pipeline — the HTML tokenizer, the CSS engine, the box-model layout, and the GDI+ painter — is implemented from scratch in around ten source files.

Networking is provided by an asynchronous WinHTTP client. Pages, stylesheets and images are downloaded in parallel; results are marshalled back to the UI thread through a small task queue, so the browser stays responsive while a page is loading.

The selector matcher buckets every CSS rule by its rightmost compound selector (id, class or tag), which keeps style resolution fast even on large pages such as Wikipedia, whose stylesheets ship tens of thousands of rules.
